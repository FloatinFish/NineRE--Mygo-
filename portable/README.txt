NineRE 本地整合版（便携）
========================================

【换到别的电脑 / 第一次使用】
1. **先双击「环境检查.bat」**（在便携包根目录）。
   它会检查 .NET Framework 4.8、WebView2 Runtime（新版启动器需要）、VC++ 运行库、
   DirectX、端口占用、目录权限、数据库数据目录与关键文件，缺什么会直接告诉你去装什么。
   缺 .NET / WebView2 / VC++ 时，启动器本身可能都打不开——所以这一步必须在启动器之前做。
   检测到 WebView2 缺失时会询问是否自动安装；离线机器可把
   MicrosoftEdgeWebView2Setup.exe 放到 tools\ 下，工具会直接用它静默安装。
2. 检查全绿后，再双击「NineRE Launcher.exe」。
3. 整个便携包可以整体拷到别的电脑（换盘符也行），
   但必须**整包拷贝**：pgsql + pgdata + Server + Game 一个都不能少。

【怎么玩】
1. 双击「NineRE Launcher.exe」。
   启动器会先拉起 PostgreSQL 与本地游戏服，三项都变「就绪」后按钮才可点。
2. 左侧选账号 → 点「进入游戏」（或按回车）。
   游戏会直接进入主城，不再出现任何登录/选号界面。
3. 想换账号：关闭游戏 → 启动器窗口会自动恢复 → 选另一个账号再进。
   ⚠ 启动器关闭时会一并停止数据库与服务器；想保持服务运行就别关启动器（进游戏后它是最小化的）。
4. 新增账号：点「＋ 添加账号」，输入账号名（密码可空）→ 直接进入，首次登录自动建号。

【账号与设置持久化】
   账号列表、画面设置保存在两份镜像里（任一份在就能恢复）：
     Game\The Nine Regions\File\palr_local_store.txt
     %USERPROFILE%\AppData\LocalLow\SOFTSTAR\The Nine Regions\palr_local_store.txt
   「删除账号」只从本机列表移除，服务端存档不会删除；重新添加同名账号即可找回进度。

【画面设置】
   启动器右侧可选 窗口化 / 全屏 与分辨率；进入游戏时生效。
   游戏内改分辨率/窗口化也会写回，下次启动器会显示最新值。

【充值】
   与以前完全一致：进入游戏后在「商店」里充值，走本地服务端下发到账。
   启动器只负责登录，不参与充值链路。

【服务端控制台】
   启动器底部可展开，实时显示服务端日志（run.log）与数据库日志（pgdata.log），
   用于排查「进不去游戏」。服务没起来时它会自动展开，并给出「重试启动服务」。

【目录说明】
   Game\The Nine Regions\   游戏客户端（已包含本地化补丁与语音）
   Server\                  本地服务端（账号/卡牌等数据在 Server\data 与 pgdata）
   pgsql\                   便携版 PostgreSQL 运行环境
   pgdata\                  PostgreSQL 数据目录（游戏进度、账号、卡牌都在这里）
   assets\                  启动器背景（登录场景循环视频）
   NineRE Launcher.exe             启动器
   服务端监视器（可选）.vbs  可选：隐藏窗口常驻监视器（直接双击 MC.exe 时也能拉起服务）

【常见问题】
   - 一直进不去：看启动器底部控制台；服务端到账问题看 Server\run.log。
   - 启动器提示缺少 WebView2：运行一次「环境检查.bat」，按提示自动安装；
     离线机器把微软的 WebView2 安装器放到 tools\ 下再运行。
   - 数据库启动失败：确认 pgdata 目录完整、路径没有只读权限。
   - 想重置进度：关闭游戏与服务端后删除 pgdata 会丢档，请先备份。
   - 彻底关闭：先结束 nine-regions-backend.exe 与 postgres.exe。

【备份 / 迁移】
   关闭游戏后，把整个 NineRegions-Portable 文件夹复制走即可；
   换盘符/换电脑也不影响（启动器自动识别目录）。
